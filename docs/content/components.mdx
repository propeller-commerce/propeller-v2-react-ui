# Component reference

The package exports 60 components. This page is the catalogue — each entry
links to that component's **generated API page** (full `*Props` table with
per-prop documentation, pulled from the TypeScript source).

Three ways to explore a component:

- **This catalogue → [API reference](/api)** — the complete prop contract
  for every component and its types.
- **[Storybook](/storybook)** — a live, interactive preview of each
  component against fixture data.
- **[API integration guides](/guides/api/overview)** — narrative docs on how
  the data-driven components and their composables talk to the backend.

Components that need infrastructure (the SDK services, the current user)
resolve it from `<PropellerProvider>` — see [Getting started](/getting-started).

Each component name links to its generated API page.
